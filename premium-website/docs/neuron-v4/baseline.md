# neuron-v4: baseline финала (до правок)

Ветка `feat/neuron-finale`, точка отсчёта — `2244824` (конец perf-v3).

## Как мерено

Прод-сборка с обвязкой: `NEXT_PUBLIC_PERF_HARNESS=1 npm run build`, `PORT=3100 npm run start`,
фикстурный бэкенд `docs/perf-v3/tools/mock-backend.mjs`. Chrome 152 headless-new,
ANGLE Metal на Apple M3 (не SwiftShader — тир определяется честно, проверено
`finale.mjs eval probe-renderer`).

Драйвер — `docs/neuron-v4/tools/finale.mjs`:
* `shots` — кадры финала на трёх соотношениях сторон (16:9 1440×810@2, 4:3 1024×768@2,
  9:19.5 412×892@3), прокрутка ставит центр названного якоря в центр вьюпорта;
* `fps` — `__perf.scrollRun(6 с)` **только по финалу**: от центра `#doctors` до низа
  документа, три прогона, медиана медиан; окно прокрутки пишется в трассировку.

Баннер cookie и занавес прелоадера гасятся до навигации
(`Page.addScriptToEvaluateOnNewDocument`): оба закрывают ровно тот низ кадра, где финал.

## Цифры

| Тир  | медиана кадра | p95 | к/с | GPUTask | главный поток |
|------|---------------|-----|-----|---------|---------------|
| high | 16.7 мс | 16.8 мс | 60.1 | 9.4 % | 11.9 % |
| mid  | 16.7 мс | 16.8 мс | 60.2 | 7.5 % | 9.9 % |
| low  | 16.7 мс | 16.7 мс | 60.2 | 4.9 % | 7.3 % |

**Важно про метод.** `scrollRun` меряет дельты `requestAnimationFrame` главного потока,
а те упёрты в vsync: на 60 Гц все три тира дают одинаковые 16.7 мс, и сравнение «стало
не хуже» на них тривиально и бессодержательно. Реальный запас виден только в занятости
GPU-процесса и главного потока за то же окно — эти две колонки и есть предмет сравнения
в отчёте. Колонки кадров оставлены, потому что их требует пункт 7 критериев приёмки.

## Кадры

`shots/baseline-{flash,mid,outro,footer}-{16x9,4x3,9x19.5}.jpg`

Что на них видно — ровно то, что описано в частях 1.1–1.6 промпта:

* `baseline-outro-16x9` — тонкая синяя ломаная на почти белом фоне, висит в пустоте.
  Ни сетки, ни пера, ни свечения: блум на светлом фоне прибавлять некуда;
* `baseline-outro-9x19.5` — в кадре меньше трети линии, обрезана с обеих сторон.
  Расчёт из 1.5 подтверждён наблюдением: 2·8.6·tan(22.5°)·0.46 ≈ 3.3 единиц при
  ширине ленты 11;
* `baseline-mid-*` — середина прочерчивания приходится на мутную середину перехода
  фона, там же ступень переброса токенов.
